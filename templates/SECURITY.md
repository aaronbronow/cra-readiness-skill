# Security Policy & Vulnerability Disclosure

## 1. Scope & Commitment
This project is committed to ensuring high cybersecurity standards in compliance with the **EU Cyber Resilience Act (Regulation EU 2024/2847)**. We welcome security researchers, partners, and users to report potential vulnerabilities responsibly.

---

## 2. Vulnerability Disclosure Contact (CRA Art. 13(5) / R.12)
To report a security vulnerability, please contact our designated security response team:
- **Security Contact Email**: `security@yourcompany.com` (or your personal security inbox)
- **PGP Key / Encryption (Optional)**: [Link or Fingerprint]
- **Alternative / Private Reporting**: Use GitHub Private Vulnerability Reporting on this repository if enabled.

Please **do not** report vulnerabilities via public GitHub issues or discussions.

---

## 3. Incident Response & Notification Timelines (CRA Art. 14 / A.3-A.6)
In accordance with CRA requirements:
- **Acknowledgment**: We aim to acknowledge receipt of vulnerability reports within 24–48 hours.
- **24-Hour Initial Early Warning (Art. 14(2))**: Upon confirming an actively exploited vulnerability affecting EU users, an early-warning report is submitted to the CSIRT / ENISA single reporting platform within 24 hours.
- **72-Hour Technical Assessment (Art. 14(3))**: A detailed notification covering estimated impact, severity, and initial mitigations is submitted within 72 hours.
- **14-Day Remediation Closure (Art. 14(4))**: A final report is filed within 14 days of a patch, update, or verified workaround being published.

---

## 4. Supported Versions & Security Updates (CRA Art. 13(8)-(9) / R.5, A.8, A.9)
All security updates are provided **free of charge** during the declared support period.

| Version / Branch | Supported | Security Update Commitment |
| :--- | :---: | :--- |
| `main` / latest release | Yes | Immediate security patches & updates |
| `< 1.0.0` | In Development | Active maintenance |

- **Declared End-of-Life (EOL)**: See `CRA.md` for our declared minimum support lifecycle (minimum 5 years or expected product lifetime).
- **Advance Notice**: Users will receive notice at least 12 months prior to product EOL where feasible.
